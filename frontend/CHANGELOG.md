# CHANGELOG (fact-check-dashboard.html)

このファイルは `frontend/fact-check-dashboard.html` の変更履歴です。
バージョン番号はツール画面のフッターに表示される `APP_VERSION` と対応します。

## 運用ルール(「常にアップできるループ」)

このツールは単一HTMLファイルの配布物であり、Webアプリのような自動更新の仕組みは
持ちません。そのため「改善を続けられる状態」を保つために、次のサイクルを回します。

1. `Task-lists.md` のバックログから次に着手する項目を選ぶ(優先度P0→P1→P2)。
2. 実装 → `frontend/fact-check-dashboard.test.cjs` にテストを追加 → 全テストPASSを確認。
3. 可能な範囲で実ブラウザ(Playwright等)による目視確認を行う(jsdomでは検出できない
   CSSレイアウト崩れ・タイミング依存のバグがあるため。過去に複数回、この工程で
   実際のバグを発見している)。
4. `SCHEMA_VERSION` を上げる必要がある変更(データモデルの追加・変更)は、
   `normalizeItem()` 等に旧データからの移行処理を必ず入れる。
5. `APP_VERSION` を上げ、このファイルに変更点を追記する。
6. `Task-lists.md` の該当タスクに `[x]` を付け、進行ログに実施内容・検証方法・
   発見した不具合(あれば)を記録する。
7. 配布済みの正規版ユーザーへは、更新後のファイルを再配布する(現状は手動配布。
   自動配布の仕組みは持たないため、配布のたびにこのCHANGELOGを案内すると良い)。

この1〜7を1タスクずつ回し続けることが、本ツールの「常にアップできるループ」です。

## v0.10.0 (2026-08-27)

ダッシュボードのデータビジュアライゼーションを強化(C4/C5/C6/C7/C9/C10)。

### 追加された主な機能
- 月次トレンドの前年同月比較(1年以上のデータが蓄積すると自動表示)
- スコア分布のヒストグラム(10点刻み)
- 軸別平均スコアのレーダーチャート(五角形、記録が無い軸は平均計算から除外)
- ダッシュボードKPIカードのドラッグ並び替え(設定は保存され次回訪問時も反映)
- 印刷時にチャートSVGがページ幅に収まるようCSSを調整
- 主要チャート(判定内訳ドーナツ/月次折れ線/ヒストグラム/レーダー)にPNG単体エクスポート機能
  (Canvas API未対応環境では例外を投げず警告するグレースフルデグラデーション)

### テスト
84件→97件に拡充。ドラッグ並び替え・PNGダウンロード・印刷時のSVG幅制限は実ブラウザ
(Playwright)でも検証済み。

## v0.9.0 (2026-08-27)

初期の外販レベル強化・機能拡張フェーズ。スキーマバージョンはv1→v7まで進行。

### 追加された主な機能
- デザインシステム刷新(トークン化・配色・SVGアイコン化)、トースト通知、
  インラインバリデーション、フローティング保存バー
- スキーマバージョニング + 正規化関数による後方互換性の担保
- グローバルエラーハンドラ、localStorage一元化ラッパー
- JSONインポートの追加/置換選択(Undo付き)、不正行スキップ+レポート
- 折れ線グラフのツールチップ・グラデーション、KPIの前月比トレンド
- 基本的なアクセシビリティ対応(label関連付け・コントラスト比・ARIA live・
  フォーカストラップ・色以外での判定表示)
- スクロール位置・フォーカスの保持(タブ切替時)
- インポートのDoS対策(サイズ/件数/文字列長の上限)
- サーバー共有時の機密情報混入チェック(簡易パターンマッチ)
- 一次スクリーニング機能: A)パターン検知スコア、B)アカウント信頼性チェック、
  C)過去メディアとの照合(知覚ハッシュ+ローカル参照DB)、生成AI疑いの目視チェックリスト
- 判定の再確認期限(次回レビュー日)
- 自由記述タグ機能(絞り込み対応)
- 複数人での担当者アサイン(担当者・ステータス)
- 判定内訳のドーナツチャート、出所区分×判定のヒートマップ
- 高解像度画像をIndexedDBへ退避(マイクロサムネイルはlocalStorage、フル解像度は
  IndexedDBに保存し非同期で差し替える設計。localStorageの容量制限対策)

### 発見・修正した重大なバグ
- **`#app`要素の委譲イベントリスナー重複バグ**: 「新規/編集」タブに2回目以降訪れると、
  `bindNewCheckEvents()`内の`app.addEventListener(...)`が積み重なり、1回のクリックで
  同じ処理が複数回実行されていた(トグルボタンが開いた瞬間に閉じる等)。要素を複製して
  差し替えることで解消。**この不具合は初回訪問時の動作確認だけでは発見できず、
  同じタブに複数回訪れる操作を経て初めて顕在化した。**
- `position:sticky`が末尾要素で機能しない問題(`position:fixed`に変更)
- クラッシュ復旧(下書き自動保存からの復元)時に`normalizeItem()`を通しておらず、
  旧スキーマの下書きでクラッシュしうる状態だった
- CSS Gridの列数不整合、モバイルでの日本語テーブル崩れ

### テスト
初期実装時の18件から72件まで拡充。CI(`.github/workflows/ci.yml`)で自動実行。
