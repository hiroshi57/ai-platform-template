# CHANGELOG (fact-check-dashboard.html)

このファイルは `frontend/fact-check-dashboard.html` の変更履歴です。
バージョン番号はツール画面のフッターに表示される `APP_VERSION` と対応します。

## 運用ルール(「常にアップできるループ」)

このツールは単一HTMLファイルの配布物であり、Webアプリのような自動更新の仕組みは
持ちません。そのため「改善を続けられる状態」を保つために、次のサイクルを回します。

1. `Task-lists.md` のバックログから次に着手する項目を選ぶ(優先度P0→P1→P2)。
2. 実装 → `frontend/fact-check-dashboard.test.cjs` にテストを追加 → 全テストPASSを確認。
3. 可能な範囲で実ブラウザ(Playwright等)による目視確認を行う(jsdomでは検出できない
   CSSレイアウト崩れ・タイミング依存のバグがあるため。過去に複数回、この工程で
   実際のバグを発見している)。
4. `SCHEMA_VERSION` を上げる必要がある変更(データモデルの追加・変更)は、
   `normalizeItem()` 等に旧データからの移行処理を必ず入れる。
5. `APP_VERSION` を上げ、このファイルに変更点を追記する。
6. `Task-lists.md` の該当タスクに `[x]` を付け、進行ログに実施内容・検証方法・
   発見した不具合(あれば)を記録する。
7. 配布済みの正規版ユーザーへは、更新後のファイルを再配布する(現状は手動配布。
   自動配布の仕組みは持たないため、配布のたびにこのCHANGELOGを案内すると良い)。

この1〜7を1タスクずつ回し続けることが、本ツールの「常にアップできるループ」です。

## v0.15.0 (2026-08-27)

オンボーディング・ドキュメント整備(M1/M3/M4/M6)、ビジネス/法務項目の対応可能な範囲での実施(L2/L3/L5/L6)。

### 追加された主な機能
- 初回起動時の4ステップ オンボーディングツアー(スキップ可、以後表示しない)
- ガイドタブによくある質問(FAQ)8問を追加

- 動画マニュアルへのリンク枠(実際の動画が無いため「準備中」と正直に表示、URLは
  `VIDEO_MANUAL_URL`で後から差し替え可能)
- 価格ページへのリンクを、専用ページ確定まで「準備中」表示に変更(L2、無関係な料金表への
  誤誘導を防止)
- ライセンス方式の限界に関する検討メモ(`LICENSE-STRATEGY-OPTIONS.md`、L3)、内部デザイン
  利用ガイドのドラフト(`BRAND-GUIDELINES.md`、L5)、本ツール固有利用条件の非公式英訳
  (`TERMS-EN.md`、L6)を作成。**いずれも実際の事業判断・法務レビューの代替ではない**旨を明記

### 発見した実バグ(テスト作成時)
- jsdomのテストで`document.body.textContent`を使うと`<script>`タグ内のJSソース文字列まで
  含んでしまい、意図しない誤検知(false positive)を起こすことが判明。対象要素を限定した
  textContentチェックに修正

### テスト
127件→136件に拡充。

### 未対応(人間の判断が必要)
- L1(提供者名の最終確認)、L4(弁護士レビュー)は、AIエージェントが代行できない業務のため
  引き続き未着手。詳細はTask-lists.md参照。

## v0.14.0 (2026-08-27)

テスト・CI基盤の強化(J3〜J8)と、動画照合・パターンカタログのノーコード編集(N11/N12)。

### 追加された主な機能
- Playwright(`@playwright/test`)導入。クロスブラウザ(Chromium/Firefox/WebKit)の
  決定的スモークテストをCIに組み込み(J7)、スクリーンショット比較によるビジュアル
  リグレッションテストはローカル専用ツールとして実装(J3、OS間のフォントレンダリング差
  によりCI化は見送り。詳細は`visual-tests/dashboard.visual.spec.js`参照)
- Lighthouse自動計測(`scripts/lighthouse-check.mjs`、J4)。実行して見つかった
  アクセシビリティ不備4件(ボタンのアクセシブルネーム欠如・コントラスト比不足・
  タップ領域不足・main landmark欠如)を修正し、スコアを84→100に改善
- HTMLバリデータ(html-validate、J5)、関数呼び出しカバレッジ計測ツール(J6)、
  `frontend/RELEASE-CHECKLIST.md`(J8)を追加
- 動画ファイルの代表フレーム抽出による過去メディア照合(N11)。動画全体・音声までは
  照合しない既知の限界をUI・印刷レポートに明記(スキーマv9、`mediaCheck.sourceType`追加)
- 誤情報パターンカタログのノーコード編集(N12)。安全のため正規表現ではなくキーワード
  部分一致方式に限定

### 発見・修正した実バグ
- CSPに`media-src`を設定していなかったため、N11の`<video>`要素によるdata:動画読み込みが
  CSP違反でブロックされていた(実ブラウザ検証で発見、`media-src data: blob:`を追加)

### テスト
119件→127件に拡充。クロスブラウザテスト・動画フレーム抽出のffmpeg生成テスト動画による
実地検証は実ブラウザ(Playwright)で実施。

## v0.11.0 (2026-08-27)

パフォーマンス改善(G3/G4/G5/G6)。

### 追加された主な機能
- 下書き自動保存の実書き込みをrequestIdleCallback(未対応環境はsetTimeout)まで遅延し、
  入力中のメインスレッド負荷を軽減
- 判定スコアの重み入力にデバウンスを導入し、連打時のチャート再描画の無駄打ちを防止
- 起動時に初回描画時間・ファイルサイズ目安を`window.__bootStats`に記録(開発者向け自己点検)
- CSV/JSONエクスポートを大量データ(300件超)時のみWeb Worker化し、UIスレッドの
  ブロッキングを防止(Worker非対応環境・生成失敗・タイムアウト時は自動的に同期フォールバック)

### テスト
97件→105件に拡充。Web Worker実使用・requestIdleCallback実使用は実ブラウザ(Playwright)
でも確認済み。

## v0.9.0 (2026-08-27)

初期の外販レベル強化・機能拡張フェーズ。スキーマバージョンはv1→v7まで進行。

### 追加された主な機能
- デザインシステム刷新(トークン化・配色・SVGアイコン化)、トースト通知、
  インラインバリデーション、フローティング保存バー
- スキーマバージョニング + 正規化関数による後方互換性の担保
- グローバルエラーハンドラ、localStorage一元化ラッパー
- JSONインポートの追加/置換選択(Undo付き)、不正行スキップ+レポート
- 折れ線グラフのツールチップ・グラデーション、KPIの前月比トレンド
- 基本的なアクセシビリティ対応(label関連付け・コントラスト比・ARIA live・
  フォーカストラップ・色以外での判定表示)
- スクロール位置・フォーカスの保持(タブ切替時)
- インポートのDoS対策(サイズ/件数/文字列長の上限)
- サーバー共有時の機密情報混入チェック(簡易パターンマッチ)
- 一次スクリーニング機能: A)パターン検知スコア、B)アカウント信頼性チェック、
  C)過去メディアとの照合(知覚ハッシュ+ローカル参照DB)、生成AI疑いの目視チェックリスト
- 判定の再確認期限(次回レビュー日)
- 自由記述タグ機能(絞り込み対応)
- 複数人での担当者アサイン(担当者・ステータス)
- 判定内訳のドーナツチャート、出所区分×判定のヒートマップ
- 高解像度画像をIndexedDBへ退避(マイクロサムネイルはlocalStorage、フル解像度は
  IndexedDBに保存し非同期で差し替える設計。localStorageの容量制限対策)

### 発見・修正した重大なバグ
- **`#app`要素の委譲イベントリスナー重複バグ**: 「新規/編集」タブに2回目以降訪れると、
  `bindNewCheckEvents()`内の`app.addEventListener(...)`が積み重なり、1回のクリックで
  同じ処理が複数回実行されていた(トグルボタンが開いた瞬間に閉じる等)。要素を複製して
  差し替えることで解消。**この不具合は初回訪問時の動作確認だけでは発見できず、
  同じタブに複数回訪れる操作を経て初めて顕在化した。**
- `position:sticky`が末尾要素で機能しない問題(`position:fixed`に変更)
- クラッシュ復旧(下書き自動保存からの復元)時に`normalizeItem()`を通しておらず、
  旧スキーマの下書きでクラッシュしうる状態だった
- CSS Gridの列数不整合、モバイルでの日本語テーブル崩れ

### テスト
初期実装時の18件から72件まで拡充。CI(`.github/workflows/ci.yml`)で自動実行。
