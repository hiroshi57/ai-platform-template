# ブランドガイドライン(内部デザイン利用ガイド・ドラフト)

> **L5の位置づけ**: これは正式な商標登録書類・法的なブランドガイドラインではなく、
> 「このツールのビジュアルを一貫して使うための内部向けデザインガイド」です。
> 商標としての正式登録・保護を行う場合は、別途弁理士・弁護士に相談してください。
> このドラフトはその際の出発点(デザイン仕様の言語化)として使えます。

## 1. プロダクト名

- 正式名称: **ファクトチェック・ダッシュボード**
- 英語表記(社内利用時の参考、正式な英語ブランド名ではない): Fact-Check Dashboard
- 表記ゆれ防止: 「・」を含めた表記で統一する(「ファクトチェックダッシュボード」等の
  中黒無し表記は使わない)

## 2. ロゴ/ブランドマーク

現在のロゴは、`fact-check-dashboard.html` のヘッダー(`<h1>`)に実装されている
インラインSVGです。

```html
<span class="brandmark" style="...background:linear-gradient(135deg,var(--accent-500),var(--accent-700))...">
  <svg ...><circle cx="11" cy="11" r="7"></circle><line .../><polyline .../></svg>
</span>
```

- **モチーフ**: 虫眼鏡(検索・調査)+チェックマーク(検証済み)の組み合わせ
- **形状**: 角丸10px・34×34pxの正方形コンテナに、白抜きのアイコンを中央配置
- **背景**: グラデーション(`--accent-500` → `--accent-700`、135deg)
- **クリアスペース**: ロゴの周囲には、ロゴの高さの最低25%(約8.5px)の余白を確保する
- **最小サイズ**: 24×24px未満には縮小しない(視認性が損なわれるため)

### やってはいけないこと
- ロゴの縦横比を変更する(引き伸ばし・圧縮)
- グラデーションの角度・色を変更する
- 白抜きアイコン部分に別の色を使う
- ロゴを回転させる

## 3. カラーパレット

`fact-check-dashboard.html` のCSS変数(`:root`)で定義されているトークンをそのまま使う。

| 用途 | 変数名 | 値(参考) |
|---|---|---|
| プライマリ(アクセント) | `--accent-500` / `--accent-700` | ブランドマーク・主要ボタンに使用 |
| 成功 | `--success-500` / `--success-600` | 真実判定・成功トースト |
| 警告 | `--warning-500` / `--warning-600` | 一部誤り判定・試用版バナー |
| 危険 | `--danger-500` / `--danger-600` | 誤り判定・削除操作 |
| ニュートラル | `--n-0`〜`--n-900` | テキスト・背景・境界線の階層 |

外部の紹介資料・スライド等でブランドカラーを使う場合も、上記のCSS変数の実際の
HEX値(`fact-check-dashboard.html`内の`:root`ブロック参照)をそのまま流用すること。
似た色を目分量で使わない。

## 4. タイポグラフィ

- 見出し・本文ともにシステムフォント(`-apple-system, "Segoe UI", ...`相当、
  CSSの`font-family`定義を参照)を使用。独自の商用フォントは使用していない
  (オフライン配布・ライセンスフリーを優先する設計方針のため)。

## 5. アイコン

すべて`ICON_PATHS`定義のインラインSVG(Feather Icons的なミニマルな線画スタイル、
`stroke-width="2"`)。絵文字は使わない(A3の方針、プラットフォーム間の見た目の
揺れを避けるため)。外部向け資料で新しいアイコンが必要な場合も、同じ線画スタイル
(角丸・2pxストローク・24×24 viewBox)で統一すること。

## 6. トーン&マナー(文言のスタイル)

- 「〜てください」調の丁寧語で統一(命令形は使わない)
- 誇張表現を避ける(「完璧に検証」「絶対に正確」等は使わない)。常に「参考情報」
  「記録に基づく」という限定を明示する(プロジェクト全体の誠実性方針、
  `.claude/agent-memory/`の関連メモリ参照)
- 機能名は日本語(「サーバー共有」「参照メディアDB」等)で統一し、英語と日本語を
  混在させない
