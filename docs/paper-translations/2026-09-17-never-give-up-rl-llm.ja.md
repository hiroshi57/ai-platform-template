## 要旨（Abstract）

我々は、LLM を RL で学習させても、データセット全体にわたって性能が均等に改善するわけではないことを示す。RL は、LLM が既に解くのが得意な**簡単な問題では大きく改善する一方、難しい問題ではわずかしか改善しない**。我々はこれを、経済学とネットワーク科学の「累積的優位（cumulative advantage）」— 俗に言う**「富める者はますます富む（the rich get richer）」**— になぞらえて、**RL for LLM におけるマタイ効果（Matthew Effect）** と呼ぶ。

素朴な説明は「難問は解を見つけるのにより多くの計算を要する」というものだ。我々は、**現代の RL 手法が簡単な問題に計算を使いすぎることで問題を悪化させている**と主張し、計算の使い方を動的に再配分すべきだと論じる。我々は **Never Give Up（NGU）** を導入する。これは、ある問題について正解が 1 つ得られるまでサンプル生成を続ける、単純な適応的サンプリング手法である。**非同期（asynchronous）RL** を活用することで、NGU は簡単な問題を少ないサンプルで自然に振り落とし、より多くの計算を難問の解決に配分する。

我々は、オフポリシー頑健性など NGU に影響する設計選択を調査し、ベストプラクティスの集合を確立する。数学ベンチマーク **Deepscaler** では、NGU は計算あたりの性能を、特に難問で改善する。最近のコーディングタスク **Manufactoria** では、テストごとの報酬を用いた標準的 GRPO は、難易度に幅のあるテストを含む問題を完全には解けない。NGU は反復的に改善し、より難しいテストを次々に解いていき、最終的にコーディング問題を完全に解けるよう学習する。

## 1. 導入（Introduction）

強化学習（RL）は、現代の AI パイプラインで大規模言語モデル（LLM）をポストトレーニングする標準的手法である（DeepSeek-AI 2025b; Olmo 2026）。事前学習・中間学習は LLM に強力な事前知識と指示追従能力を与えるが、RL によるポストトレーニングは、教師データを超えてモデルを改善させ（DeepSeek-AI 2025a）、実世界タスクへ汎化させる（Chu 2025）ことを可能にする。

実務家は一般に、**簡単〜難しい問題の範囲で RL 学習すれば、モデルは分布全体にわたって問題を解けるようになる**と仮定する。**我々はこれが真ではないことを見出した。** 図1で、我々は 3 つの異なるドメイン（数学・コーディング・エージェント的コーディング）の 3 つの異なるオープンソース RL 学習済みモデルを評価し、**難問に比べて簡単な問題が不釣り合いに大きな改善を受けている**ことを見出した。LLM への RL 適用は、**LLM が既に得意だった問題へバイアスした学習**の明確なパターンを示す。

本論文は 3 つの主要な取り組みを行う。**第2章**で、RL 学習が初期 LLM の解きやすさに比例して改善することを定義・実証する。**第3章**で、非効率な計算配分がマタイ効果の一因であることを見出す。直感的には難問はより多くのサンプルを要するが、我々は、現代の RL 手法が難易度に関わらず全問題に等しく計算を割り当てることで問題を悪化させていると論じる。簡単な問題への偽の失敗からノイズが混入しうることを示し、**動的な計算配分**を主張する。**第4章**で動的サンプリング解 **NGU** を提案する。NGU はプロンプトに補完（completion）を反復サンプリングし、(1) 正解が見つかれば停止、(2) 見つからなければキューに戻して継続する。解けないプロンプトを無限にサンプルしないよう、**確率 $p$ で継続し、そうでなければ諦める**。**第5・6章**で数学・コードの大規模 RL で NGU を経験的に検証する。

## 2. RL for LLM におけるマタイ効果

マタイ効果を実証するため、特定ドメインで RL のみで学習された 3 つのオープンソースモデルを分析する: **Olmo 3.1 RL-Zero**（数学）、**DeepCoder**（コード補完）、**DeepSWE-Preview**（エージェント的コーディング）。評価プロンプトを初期モデル性能で難易度別にグループ化する（AIME の pass@1、LCBv5 の pass@1、SWEBenchVerified の人間所要時間ベースの難易度バケット）。

図1が示すとおり、**RL の改善はモデルの初期精度にスケールする**: 初期に簡単なタスクほど大きく伸び、難しいタスクは限定的にしか改善しない。言い換えれば、**RL はモデルが既に強い所で最も改善する**。このパターンはドメイン・モデル・データセットをまたいで一貫する。これは累積的優位の一形態であり、ネットワーク科学におけるマタイ効果（Merton 1968）に類似する。元々は科学の引用パターン（著名な研究者が同等の仕事に不釣り合いな信用を得る、Zuckerman 1977）で観測された概念を、RL for LLM に適応する:

> **RL for LLM におけるマタイ効果**: RL はタスクに対する性能を、**モデルの初期能力に比例して**改善する — 簡単なタスクをより簡単にする一方、難しいタスクはしばしば難しいままにする。

この効果は LLM の初期条件に依存するため、RL における一種の**primacy bias（初期経験バイアス）**（Nikishin 2022）と見なせる。従来の RL primacy bias はゼロから学習する際のニューラルネット可塑性喪失に焦点を当てていた（Nikishin 2023）。対照的に、**マタイ効果は既存のバイアスを前提とし、強い事前知識を持つ事前学習済みモデルで発生する**。

> **図1**: RL for LLM におけるマタイ効果。3 ドメインの RL 学習済みモデル（AIME上のOlmo 3.1 RL-Zero Math、LCBv5上のDeepCoder、SWEBenchVerified上のDeepSWE）を初期モデルと比較。RL は初期モデルの性能に比例して改善する — 簡単な問題が最も伸び、難しい問題が最も伸びない。（数値例: AIME 数学で easy +0.63, medium +0.36, hard +0.03）

## 3. マタイ効果の原因

マタイ効果は、現代の RL 手法、特に **GRPO**（Shao 2024）とその変種の機構で部分的に説明できる。これらは経験的グループベースライン（Kool 2019; Ahmadian 2024）を用いる: $N$ 個の各プロンプトについて $K$ 個の補完をサンプルし、アドバンテージを各補完の報酬からグループ平均を引いて計算する:

$$A_i = r_i - \frac{1}{K}\sum_i r_i$$

帰結は明快だ — **$K$ 個の補完がすべて失敗して報酬ゼロなら、そのプロンプトは勾配に寄与しない**。この**シグナル損失（signal loss）仮説**（Xiong 2025）は直感的な説明であり、先行研究（Qu 2026a）が指摘するように、正解が一度もサンプルされないという理由だけで RL が難問を改善できないことがある。標準的な対処は $K$ を増やし、難問で少なくとも 1 つ正解をサンプルする確率を上げること（Hu 2025）である。

### 実験セットアップ

**Qwen 2.5 0.5B Instruct** を GSM8k の数学問題でファインチューニングする。不正確なデータを避けるため、検証済みサブセット **GSM8k Platinum** で学習。評価を 4 つの難易度（easy/medium/hard/extra hard）に分ける。初期モデルで各プロンプトに 1024 補完をサンプルし、pass@1 が 25%（easy）・10%（medium）・5%（hard）・0%（extra-hard）に対応する 8 サンプルを抽出。extra-hard の 3/4 は 1024 サンプルで完全に未解決。GRPO で学習し、大規模ポストトレーニング標準の**オフポリシー非同期 RL**（Noukhovitch 2024）を用いる。GRPO 勾配を受けないプロンプト（全正解 or 全不正解）はフィルタし、バッチサイズ一定を保つため active sampling を行う。3 シードで実行し平均と標準偏差を報告。

### シグナル損失か？

シグナル損失仮説を検証するため、補完数 $K$ を増やす効果を調べる。総バッチサイズ $N \times K$ を一定に保ちながら $K \in \{4, 8, 16, 32\}$（対応する $N \in \{64, 32, 16, 8\}$）で学習。**図2が示すとおり、全設定がマタイ効果を示す**。直感に反して、**最小の $K=4$ が全体で最良**であり、最難問（赤）で明確に見える。これは**シグナル損失がマタイ効果の主因ではない**ことを示唆する。総バッチサイズと学習ステップを固定すれば、各問題がサンプルされる期待回数は $K$ に関わらず一定。$K$ が制御するのは、勾配ゼロで**フィルタされるプロンプトの割合**にすぎない。$K$ を増やしても有効な学習シグナルは増えず、どのプロンプトが捨てられるかが変わるだけである。

補完数 $K$ の増加には競合する 2 効果がある。一方で $K$ が大きいほど難問で少なくとも 1 つ正解を生む確率が上がる。他方で、本来簡単な問題で少なくとも 1 つ**不正解**をサンプルする確率も上がる。結果、$K=4$ のような小さい値は簡単なプロンプトを振り落とすのに要する計算が少なく、難問の探索を続けられる。$K=32$ のような大きい値は、32 サンプル中 1 つ不正解があるだけで学習バッチに含まれるため、**既に大部分解けた問題に学習更新の大部分を割り当ててしまう**。図3が示すとおり、学習後半（ステップ200付近）には小さい $K$ ほど簡単なプロンプトを積極的にフィルタし、バッチが難問に集中していく。

### シグナル効率

我々は代替解釈 — **シグナル効率（signal efficiency）仮説** — を提案する。中心的な問題は「難問に十分な補完がサンプルされるか」ではなく、「**簡単な問題を過剰サンプルして計算を浪費していないか**」である。この観点では、RL 学習は本質的に**計算単位あたりの性能を最適化する問題**である。標準 GRPO は常に固定数 $K$ をサンプルするため、$K$ が大きすぎると既解決プロンプトへの冗長な補完に計算を浪費し、$K$ が小さすぎると難問がアンダーサンプルされ有用なシグナルにならない、という内在的非効率を生む。この観点は、小さい $K$ で始めて後で大きくする**多段カリキュラム**の有効性も説明する。ただし明示的カリキュラムは脆くハイパラに敏感なので、我々は**適応的・オンライン手法**でシグナル効率を達成することを目指す。

> **図2**: プロンプトあたり補完数 $K$ を増やしても、必ずしも難問は解けない。総バッチサイズ固定で、$K$ を増やすと（薄い線）$K=4$ を下回る（難問でも）。
> **図3**: 少ない $K$ は学習バッチを難問側にシフトさせる。少ない補完（濃い線）ほど、簡単サンプルをより積極的にフィルタし、難問への計算集中を可能にする。

## 4. Never Give Up でマタイ効果に対抗する

### 簡単なプロンプトを再サンプルしない（従来案）

最も単純な解は、簡単すぎる問題を学習後半で再サンプルから除外すること（An 2025）。問題は、これが学習分布をどんどん難しくし、「モデルは既解決問題で退行しない」と仮定してしまう点だ。付録C.2で、このフィルタ戦略を実装すると、一度完璧に解けた問題を学習後半で退行することを見出した。つまりこの手法は、**簡単な問題の性能を犠牲にして最難問を改善する**。

### Never Give Up（NGU）

我々の目標は、**全学習分布からサンプルし続けつつ、簡単なプロンプトをより速くフィルタし、計算を難問へ再配分する**ことだ。NGU を提案する。まず少数の補完（例 $K=4$）をサンプルする。全補完が正解なら、この問題を簡単すぎるとして素早くフィルタできる。全補完が不正解なら、標準手法は諦めて別問題をサンプルする。**代わりに、我々はこの問題を諦めず（NGU）、さらに $K$ 補完をサンプルし、解けるまで継続する**。ある問題は難しすぎるかもしれないので、実際には**確率 $p_{NGU}$ で継続し、確率 $1-p_{NGU}$ で諦める**。これは総サンプル数の幾何分布を生み、難問には時折多くの補完をサンプルしつつ、平均サンプル数を $\frac{K}{1-p}$ に保つ。

$N=64, K=4$ ベースラインを $p_{NGU}=0.95$ で再実行すると（図4）、**NGU は全ベースラインを上回り、その pass@1 の伸びは特に extra hard サブセットで得られる**。NGU が学習するプロンプトを見ると（図5）、**NGU は大きい $K$ と小さい $K$ の両方の利点を得る**: 学習初期はバッチに $K=32$ と同数の難問を持ち、後期は $K=4$ と同数になり、難問割合がほぼパレート最適に近づく。**NGU の成功の鍵は非同期 RL インフラ**であり、素早くフィルタされた簡単なプロンプトが難しいプロンプトで補充され、計算が簡単→難問へ再配分される。

> **図4**: NGU は最難問で改善する。全体 pass@1（左の青線）が改善し、特に最難サブセット（右の赤線）で改善。
> **図5**: NGU は難問学習でほぼパレート最適を達成。全学習ステップで難サンプル割合が最高・簡単サンプル割合が最低。

### NGU: 過去の補完を保持する

$K=4$ の素の GRPO に対する NGU のもう一つの利点は、難問でより大きなグループサイズを集めることでより豊かなフィードバックを得られることだ。$K=4$ の標準サンプリングは、非常に難しいプロンプトで時折正解をサンプルしても、アドバンテージは最大でも $1-\frac{1}{4}$ にしかならない（それ以前の多くの失敗サンプルがあっても）。NGU は過去の補完を保持し、正解が見つかった時点で**全過去補完を含む 1 つの大きな GRPO グループ**を形成することでこれを解決する。少数正解の大きなグループサイズは正解のアドバンテージを大きく増やし、稀な正解をより大きな勾配で更新できる。

欠点は、非同期 NGU 再サンプリングが過去ステップの**古い（stale）・オフポリシーな負例補完**を保持しうる点で、これが有害と示唆する研究もある（Roux 2025; Fu 2025）。対抗策として、過去 NGU 補完の**年齢（age）を追跡し、$T$ ステップ未満のもののみ保持**する。$T = \{1, 4, 8, 16\}$ で実験（$T=1$ は現在の $K=4$ 補完のみ保持）。図6が示すとおり、**性能は $T=1 \to 4$ で上がり、$T=8, 16$ で下がる**。

### NGU: カウントを保持する

$T=4$ 未満の古さの補完のみ保持するのが最適なので、それでもフィルタした古い補完を活かせると有用だ。直感的な案は、更新に使わなくても全過去補完の報酬で真の GRPO ベースライン $\bar{r}_{NGU} = \frac{1}{K_{NGU}}\sum_i r_i$ を計算すること。問題は、これがグループの平均アドバンテージを脱中心化（de-center）してしまう点（古すぎる負例をフィルタするため）。

我々は新しい解を提案する: **正例のアドバンテージを保持し、負例のアドバンテージを $\frac{n^+}{n^-}(1-\bar{r})$ に一律リスケールする**（$\frac{n^+}{n^-}$ は正例と残存負例の比）。これにより更新グループのアドバンテージ合計が 0 に保たれる。我々はこれを**anchoring the positives（正例の固定）**と呼び、2 つのベースラインと比較する。第一は単に脱中心化された合計を保つ（リスケールなし）。第二は Xiong (2025) 提案の、負例をダウンサンプルして正負を同数にし $\frac{1}{\bar{r}_{NGU}}$ でリスケールする方法。図6で比較し、**anchoring the positives が概ね良く、最難問で改善**する。特に、有用な負例を捨てるダウンサンプリングは性能に有害に見える。

> **図6**: NGU は古い/オフポリシー補完のフィルタを要するが、改善版 GRPO ベースラインに使える。$T>4$ の古い補完使用は性能劣化（左）だが、ベースライン計算には使える。正例固定が他手法（特にダウンサンプリング）を上回る（右）。

## 5. 数学: NGU のスケールアップ

より大規模・難しいタスクで手法と設計選択を検証する。

**実験セットアップ**: **Qwen 3 4B-base** を Deepscaler 数学の 10k サブセットで学習し、最近の数学コンテスト **AIME 2025** と **BRUMO Nov 2025** の難問で評価。初期モデルの pass@64 で難易度分け（hard = pass@64が0、medium は平均2.9%、easy は平均46.1%）。ベースラインは $K \in \{16, 32, 64\}$（対応 $N \in \{8, 4, 2\}$）。NGU は $K=16, N=8$ で $p_{NGU} \in \{0.5, 0.75, 0.875\}$（理論平均サンプル範囲 $K=32, 64, 128$ に相当）。公平な比較のため約 120 H100 時間で計算量を揃え、各設定 3 シード。

**NGU は easy/hard の性能トレードオフを改善する**（図7）: ベースラインで $K$ を増やすと easy と hard の間で性能がトレードオフする。$p_{NGU}$ を変えると、**easy の性能をさほど犠牲にせず hard でより改善**する、より良いトレードオフになる。GSM8k 同様、NGU の成功は学習バッチに暗黙的により多くの難問を持つことに帰する。

**NGU はカリキュラム学習を上回る**: プロンプトごとに初期性能で $K$ を設定する単純なカリキュラムと比較。難問への固定・大きな $K$ は計算再配分に成功し最難サブセットで NGU に匹敵するが、**簡単な問題の性能を劣化させる**。これは難易度推定が動的で学習中に変化しうることを示す。

> **図7**: NGU は hard/easy 間の性能トレードオフを改善できる。Deepscaler で学習し AIME・BRUMO 2025 で評価。NGU が全選択肢を上回り、特に最難問で優れる。$p$ を変えると $K$ を変えるのと同様のトレードオフ。

---

## 6. コーディング: プロンプト難易度からテスト難易度へ

コード生成は数学と違い、**プロンプト間だけでなく単一プロンプト内のテスト間にも難易度差**を含みうる。標準 RL が最難テストを解けない難コーディングタスクで NGU の利点を示す。

**実験セットアップ**: 最近のコーディングベンチマーク **Manufactoria**（色付きテープパターンでロボットを仕分ける工場を作る Flash ゲーム。有限状態オートマトンやタグシステム構築に類似し、複雑な OOD 学習を評価）。**Qwen3 4B Instruct** を多様で挑戦的な問題集合で学習し、汎化を測るテストセットで評価。各問題は 14〜30 のテストケースを含み、最後のテストケースはしばしば非常に難しく、いくつかは解けても全テスト通過は困難。

**ハーネス認識マタイ効果（Harness-Aware Matthew Effect）**: 初期モデル Qwen 3 4B Instruct から 128 サンプルを取り各プロンプトに難易度を割り当てる。GRPO で学習し難易度別の性能を時系列でプロット。**図8（左）では意外にもマタイ効果が見られない**。これは Manufactoria が新規タスクかつ、出力を要件に従わせるための長く新規なプロンプトを使うためと説明できる。**初期のモデルはプロンプトに適応していない**。初期の RL ステップは真のタスク改善というより**モデル能力のプロンプトへの適応**である。学習は (1) タスク・プロンプトへの適応、(2) 指定プロンプトでタスクを解く学習、の 2 相を示す。そこで、**プロンプト/ハーネス適応が完了した後（ステップ100付近）のモデルでマタイ効果を測る**ことを提案。適応後に難易度を再分類すると（図8右）、**再び明確なマタイ効果が現れる**:

> **RL for LLM におけるハーネス認識マタイ効果**: RL は、**プロンプトやハーネスへの適応を勘案した後の**モデルの初期性能に比例して、タスク性能を改善する。

**テストにおけるシグナル効率**: Sun (2025) は、テストごと報酬の GRPO ベースラインがタスクを完全には解けないと観測した。モデルは全コーディングテストの約 80% を解けるようになったが、任意の問題の全テストを通過することは稀だった。我々はこれをシグナル効率仮説で解釈する。標準 RL 実行は最簡テストはほぼ常に解き、最難テストは 20% 成功を超えることが稀で、報酬変動の大半は中難易度テストの不安定な解決から来る。結果、**学習シグナルの大半が、最難の未解決テストの進捗ではなく、部分的に解けたテストの再訪に配分される**。対照的に、NGU は過去の解を上回る軌跡にサンプリングを適応的に集中し、最難・最も情報的なテストケースへ計算を配分する。

同設定に $p_{NGU}=0.95$ だけ追加して Manufactoria で NGU を実行（図9）。標準 GRPO が全テストを解けず最難テストサブセットで停滞するのを確認。対照的に、NGU は初期は全体テスト通過率でわずかに劣るが、**hard テストで改善を続け、最終的に全テスト解決・問題完全通過へその能力を転移する**。

> **図8**: ハーネス認識マタイ効果。学習開始時（左）または適応後100ステップ（右）の pass 率で難易度判定。適応後の難易度でマタイ効果が明確に現れる。
> **図9**: NGU はコーディング問題の最難テスト解決を可能にする。GRPO が停滞しても NGU は全テストで改善を続け（左）、差は hard テストで生じ（中）、NGU は全テスト通過を学習する一方 GRPO は 1 例も全テスト通過できない（右）。

**RL における primacy bias との比較**: Sun (2025) が Manufactoria を解けた唯一の方法は、まずテストごと報酬で学習し、性能が停滞したら全テスト通過時のみ報酬を与える設定で再スタートすることだった。両者を 3000 ステップ後の最終 GRPO チェックポイントから開始して比較すると（図10）、**テストごと報酬 + NGU は全テスト報酬に計算効率でほぼ匹敵**する。興味深いことに、この結果は **RL for LLM が 3000 ステップ次善の目的で学習しても後で良いシグナルを与えられれば回復できる**ことを示す。対照的に RL の primacy bias（Nikishin 2022）は、ゼロから学習した RL モデルが可塑性喪失で初期の悪い軌跡から回復できないと見出した。**この結果は、RL for LLM が同じ可塑性喪失を被らず、マタイ効果は primacy bias の一形態でありながら可塑性喪失とは別物である**ことを含意する。

> **図10**: NGU はテストごと報酬に過適合した次善モデルから回復できる。テストごと報酬 + NGU は全テスト報酬の標準 RL と同程度の性能。

## 7. 関連研究（Related Work）

RL for LLM で難問解決に取り組む研究の多くは、外部情報の活用（Qu 2026a; Wu 2026）、GRPO 損失の修正（Tajwar 2026）、テスト時探索の改善（Hubert 2026）に焦点を当ててきた。別の系統は明示的な難易度カリキュラムの構築に焦点を当てる（簡単問題の除去 An 2025、明示的データセットのキュレーション Luo 2025c、サンプルデータ分布の調整 Shi 2026 ほか）。**NGU はデータ分布を明示的にシフトせず、計算あたり性能を改善するよう暗黙に適応する**ため、これらは NGU と直交・相補的である。

NGU に最も近いのは **Reinforce-Ada-Seq-Positive**（Xiong 2025）で、これは計算再配分（シグナル効率）ではなく難問のアンダーサンプル（シグナル損失）の解決を狙う。この違いは彼らが**同期 RL** を使うことに起因し、それが NGU の計算効率の利点を消してしまう。LLM 以前の RL は疎報酬タスクの探索の観点から難シナリオに取り組んだ（Bellemare 2016 ほか）。現在の RL for LLM は MDP ではなく単純な contextual bandit なので、この設定では NGU で十分と我々は考える。

---

## 8. 結論（Conclusion）

本研究で、我々は RL for LLM におけるマタイ効果を明らかにし、標準手法が最難問で不釣り合いに悪い性能を生むことを示した。これはまた、**単純なスカラー値では LLM の正確な評価に不十分な場合があり、密な（dense）評価シグナルへ向かうべき**ことを示す。提案手法 **Never Give Up** は、計算をより良く配分する単純な手法であり、難タスクで実質的な改善を可能にする。

将来研究では、より複雑な多段・エージェント的環境を検討しうる。RL の実現可能性は常に性能と計算のトレードオフに帰着するため（Khatri 2025）、RL の将来のスケーリングは、ますます難しいタスクを効率的に解き進める方法を見つけ続けねばならない。
