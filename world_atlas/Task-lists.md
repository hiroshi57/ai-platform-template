# せかい3Dデジタル図鑑 — Task-lists

> 目的: 国連・国際機関・世界の大学/研究機関が公開する「世界の事実データ」を集め、
> 200か国以上を **3D地球儀 × 図鑑** として、中学生・高校生でも地図帳のように
> 比較・分類・理解できる形で可視化する。データは定期的に自動更新する。
>
> 運用ルール: 終わったタスクは `- [x]` にして末尾に `(完了 YYYY-MM-DD)` を付けて消化する。
> 未着手は `- [ ]`、着手中は `- [~]`。タスクを消すのではなく状態を更新して経緯を残す。

## 1. 章立て(図鑑の構成)

| 章 | タイトル | 主な中身 | 主なデータ源 |
|---|---|---|---|
| 序章 | 地球儀で世界を旅しよう | 3D地球儀・使い方・国の検索 | Natural Earth |
| 第1章 | 🗺️ 地球のすがた(地理・地形) | 面積・人口密度・森林・農地・降水量・最高地点/最低地点・地形・自然災害 | WB / CIA |
| 第2章 | 🌡️ 気候と環境 | CO₂・エネルギー・再エネ・PM2.5・水ストレス・気候区分の説明 | WB / CIA / OWID |
| 第3章 | 👥 人口と人びと | 人口・増加率・高齢化・出生率・都市化・言語・宗教・民族 | WB / CIA |
| 第4章 | 🦋 生き物と自然(生物学) | 絶滅危惧種(哺乳類/鳥/魚/植物)・陸と海の保護区 | WB(IUCN) |
| 第5章 | 💰 経済とくらし | GDP・1人あたりGDP・成長率・貧困・格差・電気・インターネット | WB |
| 第6章 | 🏥 健康と命 | 平均寿命・子どもの死亡率・水・トイレ・栄養・医療費 | WB |
| 第7章 | 🎓 教育と科学 | 識字・就学・進学・教育費・研究開発費・科学論文 | WB |
| 第8章 | 🌱 人間開発(UNDP) | HDI・ジェンダー不平等(GII)・不平等調整HDI・地球負荷調整HDI | UNDP |
| 第9章 | 🕊️ 平和・紛争・政治 | 武力紛争の死者・殺人・軍事費・難民・女性議員 | WB / UNHCR / UCDP(ウプサラ大) |
| 第10章 | 📜 歴史のデータ(数百年の変化) | 人口(紀元前1万年〜)・1人あたりGDP(Maddison)・寿命・子どもの死亡率・民主主義(V-Dem 1789〜)・CO₂(1750〜) | OWID(大学) |
| 第11章 | 🧭 世界史年表 | 古代〜現代の出来事(政治・戦争・科学・生物学・環境)と関係国を地球儀で表示 | 手作り年表 |
| 第12章 | 🎯 SDGs 17の目標 | 目標別の関連指標・国別SDGsカード | WB / UNDP / UN |
| 第13章 | 📘 国別図鑑ページ(200+か国) | 国旗・基本情報・日本語概要・全指標の世界比較・推移・2030予測・総評 | 全ソース |
| 付録 | 出典・更新日・免責 | データの出所・ライセンス・注意点 | — |

**見せ方(モード)**: 地球儀 / ランキング / くらべる(最大4か国) / 分類(地域・所得・散布図) / 年表 / SDGs / 図鑑ページ
