# 15. ファシリテーター向け運営ロジ（TASK-17）

[07：育成カリキュラム](07_training_curriculum.md)を実際に開催する際の、
会場・人数・タイムテーブル・配布物などの運営詳細。カリキュラムの
内容設計（何を学ぶか）と運営ロジ（どう回すか）を分離して管理する。

## 15.1 推奨人数・会場

| 項目 | 推奨値 | 理由 |
|------|--------|------|
| 参加人数 | 6〜12名 | セルフチェック演習（[02](02_six_principles.md)）を全員が発言できる規模の上限が12名程度。6名未満だと議論の多様性が不足しやすい |
| メンター数 | 参加者6名につき1名 | 演習後のディスカッションでグループを分ける場合、各グループに1名は経験者を配置する |
| 会場形式 | 島型（4〜6名ずつの島） | グループ演習（[07.1](07_training_curriculum.md)の主要演習列）がテーブル単位の議論を前提としている |
| オンライン代替 | ブレイクアウトルーム（4〜6名） | 対面と同様の島型構成をオンラインでも再現する。[14のクイズバンク](14_quiz_bank.md)はチャットや投票機能で実施可能 |

## 15.2 90分タイムテーブル（標準テンプレート）

| 時間 | 内容 | 備考 |
|------|------|------|
| 0:00〜0:05 | ウォームアップクイズ（[14](14_quiz_bank.md)該当セクション5問） | 前回の復習も兼ねる |
| 0:05〜0:15 | 当日テーマのミニ講義 | 資料の要点のみ。詳細は事前配布資料で読了済み前提 |
| 0:15〜0:20 | 演習の説明・グルーピング | |
| 0:20〜0:55 | グループ演習（[07.1](07_training_curriculum.md)の主要演習列） | 各自の記入時間10分＋グループ議論25分の目安 |
| 0:55〜1:15 | 全体共有・ディスカッション | 各グループ3分程度で発表、メンターがコメント |
| 1:15〜1:25 | 実践課題の確定 | 次回までに実務で1つ試すことを個人で言語化 |
| 1:25〜1:30 | クロージング | 次回予告、[08の用語集](08_glossary.md)等の参照案内 |

> Week8（総合ケーススタディ＋批判的視点、[07.2](07_training_curriculum.md)・
> [12](12_critical_perspectives.md)）は演習項目が多いため、120分への延長を推奨する。

## 15.3 事前配布物チェックリスト（各回1週間前までに送付）

- [ ] 当日該当する資料ファイル（例：Week2なら[02](02_six_principles.md)）のリンクまたはPDF
- [ ] 前回の実践課題の振り返りフォーム（1〜2行で記入できる簡易フォーム）
- [ ] 当日使うワークシート（各ファイル末尾の演習テーブルを印刷用に切り出したもの）
- [ ] （Week5・7）[10_templates.md](10_templates.md)・[11_agile_hybrid_bridge.md](11_agile_hybrid_bridge.md)のテンプレート実物

## 15.4 当日持ち物・設備チェックリスト（ファシリテーター用）

- [ ] プロジェクター／画面共有環境
- [ ] ホワイトボードまたはオンラインホワイトボード（[05.2の2軸マトリクス](05_success_criteria.md)、
      [10.4のパワー・関心グリッド](10_templates.md)など図を書きながら説明する場面が多い）
- [ ] タイマー（グループ演習の時間管理）
- [ ] 付箋・マーカー（対面の場合。オンラインなら付箋アプリ）
- [ ] [14のクイズバンク](14_quiz_bank.md)を出題形式に変換したもの（投票アプリ等）

## 15.6 開催後のふりかえり（研修そのものの改善ループ）

- 各回終了後、ファシリテーターは5分でよいので「今回うまくいった点／
  次回改善する点」を記録する
- 8回終了後、[task-lists.md](task-lists.md)と同じ形式で
  「研修運営タスクリスト」を作り、次期開催に向けた改善事項を積み残さない
  （本ファイル自体もその対象に含める）
