# 14. 知識定着クイズバンク（TASK-15）

07の育成カリキュラム各回の冒頭5分、または修了時の知識確認として使う
多肢選択式クイズ。演習（自己申告制の振り返り）と異なり、**客観的な正誤で
知識定着を確認できる**ことを目的にしている。

> 出題範囲は本資料集（`01`〜`13`）に基づく。第8版の`要検証`マーカーが付いた
> 論点（パフォーマンス領域の正式名称・40プロセスの詳細）は、断定的な正誤を
> 問う設問には含めていない（誤った「正解」を教えることになるため）。

## 使い方

- 各回の該当セクションを、Week開始時のウォームアップ（5問・5分）として使う
- 修了時（Week8）は全問（総合テスト）として使い、[07.3の評価ルーブリック](07_training_curriculum.md)の
  「原理原則の理解」軸の補助データとする
- 正解は各設問の下に隠す形にせず、末尾の「解答一覧」にまとめている
  （ファシリテーターが印刷して配布する際は、解答一覧のページだけ切り離すこと）

## セクションA：PMBOKの全体像・版の変遷（[01](01_overview_history.md)対応）

**A1.** PMBOKの説明として正しいものはどれか。
1. プロジェクトの実行手順を一意に定める「手順書」である
2. プロジェクトマネジメントの知識体系を示す「フレームワーク」であり、テーラリングが前提
3. アジャイル開発専用のガイドである
4. PMI加盟企業のみが使用を許可されている

**A2.** 第8版の構成の軸として正しいものはどれか。
1. プロセスベースのみ
2. 原理原則ベースのみ
3. 原理原則＋プロセスの統合
4. パフォーマンス領域のみ

**A3.** プロジェクトとプログラムの違いとして正しいものはどれか。
1. プログラムの方が短期間で完了する
2. プログラムは、関連する複数プロジェクトを一括管理した方が便益が大きい場合の集合である
3. プロジェクトとプログラムは同じ意味で使われる
4. プログラムはPMBOKガイドが直接扱う対象である

**A4.** 第6版の「10知識エリア・49プロセス」という数字について正しい理解はどれか。
1. 第1版から一貫してこの数字だった
2. 第6版（2017年）時点の数字であり、版が進むごとに増えてきた経緯がある
3. 第7版以降も同じ数字が使われている
4. PMPの出題範囲（ECO）と完全に一致する数字である

## セクションB：6つの原理原則（[02](02_six_principles.md)対応）

**B1.** 「価値に注力する」原則の説明として最も適切なものはどれか。
1. 価値は最初に確定した事実であり、途中で見直す必要はない
2. 価値は仮説であり、複数視点で検査・適応し続けるべきものである
3. 価値の評価はPMが単独で行うべきである
4. 価値は必ず金額換算できるものだけを指す

**B2.** 「説明責任を果たせるリーダーとなる」原則が求めているものはどれか。
1. すべての判断をPMに集約すること
2. チーム全員が自分の担当範囲で判断し、行動できる状態を作ること
3. 説明責任はプロジェクトスポンサーのみが負うこと
4. リーダーは判断の根拠を明かす必要はないこと

**B3.** 「すべてのプロジェクト領域に持続可能性を統合する」の説明として不適切なものはどれか。
1. チームの残業状況を進捗指標と同じ重みでモニタリングする
2. 技術的負債を可視化し計画に組み込む
3. 環境配慮（ESG）だけを指す概念である
4. 「今回だけの特別対応」を繰り返さない

**B4.** 「権限付与された文化を構築する」の実践例として最も適切なものはどれか。
1. 裁量権を渡せば、それだけで十分である
2. 悪いニュースを最初に報告した人を評価する運用を明示的に作る
3. 立場が上の者の判断には異議を唱えないルールを作る
4. ふりかえりは形式的な報告会にとどめる

**B5.** 第7版の12原則のうち、第8版では明示的な後継原則が無く、
プロセス側の機能に溶け込んだ可能性がある（本資料集での仮説）とされているのはどれか。
1. Value（価値）
2. Quality（品質）
3. Tailoring（状況に応じた調整）／Risk（リスクへの最適対応）
4. Systems Thinking（システム思考）

## セクションE：AI・アジャイル・実践テンプレート（[06](06_ai_contemporary_theme.md)・[10](10_templates.md)・[11](11_agile_hybrid_bridge.md)対応）

**E1.** PMBOKにAIというテーマが加わった際の本資料集の立場として最も適切なものはどれか。
1. AIを使うこと自体が価値である
2. AIの提案は常に人間の判断より優先すべきである
3. AIを活用しても、PMとしての説明責任の所在を明確にすべきである
4. AI活用の判断は現場に一任し、PMは関与しなくてよい

**E2.** RACIマトリクスにおいて、1つのタスクに複数人の「A（説明責任）」を
割り当てることについて正しい説明はどれか。
1. 推奨される運用である
2. 説明責任が曖昧になり、原則4（説明責任を果たせるリーダー）が機能しにくくなる
3. Rを割り当てる人数に制限があるため代わりに使う
4. アジャイルプロジェクトでは必須の運用である

**E3.** ハイブリッド開発アプローチにおいて、一般的に「予測型」で固定すべき領域として
本資料集が挙げているものはどれか。
1. UI/UXの詳細仕様
2. 内部の実装順序
3. 全体予算の上限や法規制対応
4. 機能の詳細仕様

## セクションF：批判的視点（[12](12_critical_perspectives.md)対応）

**F1.** 本資料集が指摘する「PMBOKへの批判」として妥当性が高いとされているものはどれか。
1. PMBOKは特定の宗教団体が発行している
2. プロセス・テンプレートを揃えること自体が目的化する形式主義に陥りやすい
3. PMBOKには原則が一切存在しない
4. PMBOKはアジャイルの発案元である

**F2.** 「PMBOKを疑うべき状況」として本資料集が挙げているものはどれか。
1. リスク登録簿を継続的に更新し、意思決定に活用している
2. 5人以下の小規模プロジェクトで変更管理委員会（CCB）のような重厚な機関を設置しようとしている
3. 原則に基づいて具体的な行動を決めている
4. 現場の反対意見を踏まえてフレームワークを調整している
