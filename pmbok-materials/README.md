# PMBOK まとめ資料集 — プロマネ育成キット（第8版対応）

2026年4月に発売された **PMBOK 第8版（日本語版）** を軸に、プロジェクトマネージャーを
育てるための社内研修資料集。PMI公式ガイドの「要約」ではなく、**現場で使うための実践資料**
として構成している。

> ⚠️ **一次情報についての注記**
> 第8版は2026年4月刊行の最新版であり、本資料集の一部（特に「7つのパフォーマンス領域」の
> 具体名称、「40のプロセス」の詳細リスト）は執筆時点で公式ガイド原文と照合できていない箇所を
> `要検証` として明示している。研修に本格投入する前に、必ず公式ガイド（日本語版）の該当ページと
> 照合し、`要検証` マーカーを外すこと。ユーザーから確定情報として提供された内容（版の変遷、
> 6原理原則の内容、AIというテーマの追加、成功評価の二軸）はそのまま採用している。

## 使い方

1. **新任PM・PMO配属者** → 09（適用範囲）→ 01 → 02 → 05 → 06 の順に読み、07の Week1〜2 を実施
2. **PMP受験予定者** → 09（PMBOKとPMP試験ECOの違いに注意）→ 01 → 02 → 03 → 04 を精読し、04のワークシートで第6版プロセスとの対応を自分で埋める
3. **研修設計者** → 07 を土台に社内カリキュラムを組み、各回の教材として 02・03・05・06・10・11・12 を配布し、[15](15_facilitator_logistics.md)で運営を組み立てる
4. **既存プロジェクトの振り返り** → 05 の評価軸を使って直近プロジェクトを採点し、ギャップを02の原理原則にマッピングする
5. **アジャイル／ハイブリッド案件のPM** → 02 → 11 の順で、Scrum実務との対応関係を先に押さえる
6. **日本企業の組織文化を踏まえて導入したいPM/PMO** → 02 → 13 の順で、稟議・下請け構造・根回しとの整合を確認する
7. **知識定着を客観的に測りたい研修設計者** → 各回のウォームアップに [14](14_quiz_bank.md) を使用する
